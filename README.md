## How I approach technical work

- **Hands-on debugging:** Reproduce a problem, read the relevant code, change the logic, and rerun the scenario to verify the fix.
- **Manual and automated QA:** Check normal inputs, invalid inputs, boundary cases, expected versus actual behavior, and test output. Automated test results supplement—not replace—manual verification.
- **Systems and data validation:** Check source records, investigate mismatches, trace workflows, and document what changed.
- **AI-assisted tools, independently checked:** Use assistance where helpful while reviewing outputs, understanding the implementation, testing behavior, and being clear about project scope.

**Tools I’m learning and using:** SQL (PostgreSQL), Python, JavaScript, HTML/CSS, Power BI, Excel, pytest, REST APIs, Windows, SAP, and Salesforce CRM.
